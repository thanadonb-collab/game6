# HAUPTTÜR — Character Demo (Godot)

เกม 3D Tower Defense **HAUPTTÜR** ใช้ฉากโชว์ตัวละคร ผู้เล่นเป็นจอมพลของอาณาจักรเอลวาเรน ที่ต้องปกป้องเมืองจากกองทัพสมัยใหม่ซึ่งบุกเข้ามาทางประตูมิติ

**ทดลองเล่นบนเว็บ:** https://thanadonb-collab.github.io/game6/

## ตัวละคร
| ตัวละคร | ฝ่าย | อาวุธ |
|---|---|---|
| จอมพลอัลดริก (ตัวผู้เล่น) | อาณาจักร | ดาบรูน + โล่ |
| เซอร์เคเลน | อาณาจักร | ดาบ + โล่ทรงว่าว |
| ซิลเวน | อาณาจักร | ธนูเอลฟ์ |
| อัครจอมเวทไลรา | อาณาจักร | ไม้เท้าคริสตัล |
| ทหารข้ามมิติ | ศัตรู | ปืนไรเฟิล |

ท่าทาง: Idle, Walk, Run, Attack, Block, Cast, Command, Hit, Death, Victory

## เปิดใน Godot
1. เปิด Godot 4.5 ขึ้นไป แล้ว Import ไฟล์ `project/project.godot`
2. กด **F5**

## การควบคุม
| ปุ่ม | การทำงาน |
|---|---|
| WASD / ลูกศร | เดิน |
| Shift | วิ่ง |
| คลิกพื้น | เดินไปจุดนั้น |
| ลากเมาส์ / ล้อเมาส์ | หมุนกล้อง / ซูม |
| J · K · Q · E | โจมตี · ป้องกัน · ปลุกขวัญ · สั่งการ |
| H · X · V · R | ถูกโจมตี · พ่ายแพ้ · ฉลองชัย · ฟื้นคืน |
| ปุ่ม `<` `>` | สลับตัวละคร |
